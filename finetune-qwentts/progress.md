# Progress - Qwen3-TTS 0.6B x Sheng (Swahili + English)

Base model: `Qwen/Qwen3-TTS-12Hz-0.6B-Base` (talker LM, 12 Hz x 16 codebooks,
24 kHz via `Qwen3-TTS-Tokenizer-12Hz`).
Dataset: `lyle-mlengineer/kenyan-celebs` - 42 clips x 30 s, 21 min, single
speaker `abel`, Sheng.
Method: single-speaker SFT of the **talker only**; the speaker embedding is baked
into `codec_embedding[3000]`, producing a CustomVoice checkpoint
(`speaker="abel"`, no reference audio needed at inference).
