## Notes so far (local, CPU-only box)

* data stage verified end to end: 42 clips -> 21.0 min of 24 kHz mono PCM16,
  38 train / 4 val, reference clip `utt_0010` cut at 8.36 s on a 0.78 s pause.
  Source audio is 22.05 kHz despite the dataset card saying 16 kHz; resampled
  with `scipy.signal.resample_poly` (numpy polyphase fallback when scipy is
  absent, both tested).
* all 56 transcript characters are in Sauti's 2545-entry vocab; 0 digits,
  17 apostrophes, 0 non-ASCII. F5's `convert_char_to_pinyin` is identity on
  every transcript and on the three Sheng probes.
* the release's text embedding has **2546** rows, not 2545: F5's
  `TextEmbedding` allocates `nn.Embedding(text_num_embeds + 1, ...)` for its
  filler token. The model stage checks rows == `len(vocab) + 1`; comparing
  against `len(vocab)` was an off-by-one and is covered by tests.
* `pytest -q` -> 74 passed / 1 skipped (torch-only shim test skipped here).
* training has **not** been run on this box: no CUDA GPU. First real run must be
  on Colab (T4 is the default profile; L4/A100 are faster).
